# QABB — Drive consolidation checklist

Everything below is optional cleanup. The index already works as-is (it links to the

OCR'd copies wherever they are). Do this only if you want the searchable OCR'd PDFs to

live *inside* `QABB Indexed Documents` and the redundant scans/duplicates gone.


**Why the index won't break:** moving or renaming a file in Google Drive keeps its

file ID, so every link in `QABB_document_index.html` stays valid after a move. Deleting

the old scans is safe because the index no longer points at them (it points at the

`_OCR.pdf` copies). 


> Tip: to move a file in Drive, open the folder link, right-click the file ▸ **Organise ▸ Move**,

> or drag it. To delete, right-click ▸ **Move to bin** (recoverable for 30 days).
